## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `B-Jones-RFD/next-ddd-starter`, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default five labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: `GLOSSARY-MAP.md` at the repo root points to one `GLOSSARY.md` per context in `src/modules/<context>/`; ADRs live in `docs/adr/`. See `docs/agents/domain.md`.
